## ✨ Overview

Sunrise Solar is a front-end website designed to give a solar-energy business a clear and professional digital presence. It presents solar solutions and services through a clean, modern interface that is easy to navigate and pleasant to browse on any device.

## 🚀 Features

- Modern, clean user interface
- Solar-energy focused landing page
- Professional navigation
- Hero section with a strong visual introduction
- Solar products and services presentation
- Call-to-action sections to guide visitors
- Responsive layout for desktop, tablet and mobile

## ⚙️ Installation & Setup

This is a front-end project, so no build step is required.

```bash
# Clone the repository
git clone https://github.com/GhousDeveloper/Solar-Panel-Website.git

# Move into the project folder
cd Solar-Panel-Website
```

Then open `index.html` in your browser, or use a local server such as the VS Code **Live Server** extension.
